# MindCare — Mental Health Resource

MindCare is a web-based mental health resource and assessment application designed to provide users with accessible mental health information, resources, and support.

## 📌 About the Project

The main purpose of MindCare is to create an easy-to-use platform where users can explore mental health resources and access helpful information in one place. The project focuses on creating a simple and user-friendly interface for mental health awareness and support.

## 🚀 Features

- Mental health resources
- Mental health assessment
- User-friendly interface
- Mental health awareness information
- Resource-based support
- Simple navigation
- Responsive web design

## 💻 Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## 🎯 Objective

The objective of MindCare is to provide users with an accessible web platform containing useful mental health resources and assessment-related features.
